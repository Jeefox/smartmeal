# Автоматический сбор каталога Чижика

Магазин по умолчанию: HDC5 — Тула, Красноармейский проспект, 25.
Сборщик открывает официальный каталог Firefox, получает ссылки категорий,
затем запрашивает их JSON в отдельной браузерной сессии. Авторизация и партнёрский токен
не требуются в коде, но сайт может заблокировать доступ (HTTP 403). Проверки защиты не обходятся.

Из корня проекта:

```bash
npm --prefix frontend ci
node frontend/node_modules/playwright/cli.js install firefox
node scripts/collect_chizhik.mjs --headed
```

Для непрерывной работы с обновлением раз в неделю:

```bash
node scripts/collect_chizhik.mjs --headed --watch
```

После ошибки повтор выполняется через сутки. Остановить процесс можно Ctrl+C.
Если сайт требует проверку человека, на компьютере с графическим окружением выполните:

```bash
node scripts/collect_chizhik.mjs --setup
```

В открывшемся отдельном Firefox самостоятельно завершите проверку сайта и откройте каталог.
Затем нажмите Enter в терминале. Сборщик проверит наличие каталога, сохранит свою сессию
и сразу загрузит категории в том же окне. Для следующих запусков используйте --headed.
Успешная ручная настройка не гарантирует,
что сайт разрешит фоновую загрузку: CAPTCHA может потребоваться снова.
На сервере без графического окружения интерактивная настройка недоступна.
`profile-firefox` внутри каталога вывода содержит cookies сборщика: не публикуйте эту папку.
Личный профиль Firefox не используется. Параметр `CHIZHIK_BROWSER=chromium` возвращает Chromium
(нужна отдельная установка Chromium через Playwright и отдельная настройка сессии).
На сервере процесс следует запускать через менеджер служб под отдельным пользователем;
это не требует, чтобы Firefox пользователя был открыт. Не следует копировать рабочий профиль Firefox.

Параметры окружения:

* `CHIZHIK_STORE_ID` — код магазина, по умолчанию HDC5.
* `CHIZHIK_OUTPUT_DIR` — каталог файлов, по умолчанию `data/runtime/chizhik`.

`latest.json` заменяется атомарно только после загрузки всех обнаруженных категорий.
`status.json` содержит результат последней попытки. При 403 цены не обнуляются,
не подставляются из тестовых файлов и дата успешной загрузки не обновляется.
После аварийного завершения сначала убедитесь, что процесса нет, затем удалите пустую
папку `collector.lock` командой rmdir.

Backend после перезапуска проверяет снимок через минуту, далее раз в час.
Настройки `smartmeal.prices.chizhik.snapshot` и `smartmeal.prices.chizhik.store-id`
должны соответствовать пути вывода и магазину сборщика. Он использует обычную цену,
консервативное сопоставление ингредиентов и известные фасовки. Неизвестные единицы,
вес без заливки и неоднозначные совпадения пропускаются. Цены пока публикуются как
каталожные ориентиры с указанием магазина; ручные наблюдения цен имеют отдельное хранение.
Срок действия — 15 дней с момента загрузки; чтение файла не продлевает этот срок.

Проверки:

```bash
node --test scripts/chizhik_collector.test.mjs
node scripts/collect_chizhik.mjs --validate /path/to/category.json
```

На компьютере разработки 20 октября 2026 года сайт вернул HTTP 403 и обычному HTTP-клиенту,
и Chromium. Firefox в headless-режиме получил CAPTCHA с HTTP 200.
После ручной настройки отдельной сессии загрузка категорий в оконном Firefox (--headed)
заработала. Headless после этого всё равно запрашивал CAPTCHA. На сервере необходимо
отдельно проверять доступ с его IP и графическое окружение: локальный успех не гарантирует серверный.
