## Дикси: запуск загрузчика

Использует установленный Playwright Firefox из frontend/node_modules.
Не требует выбора магазина и не использует личный браузерный профиль.

```bash
node scripts/collect_dixy.mjs
node scripts/collect_dixy.mjs --watch
```

Режим --watch повторяет загрузку через 7 дней после успеха или через сутки после ошибки.
Процесс должен работать; постоянная системная служба этой командой не устанавливается.
При необходимости доступен --headed. Параметр DIXY_OUTPUT_DIR задаёт папку вывода;
по умолчанию используется data/runtime/dixy, которая исключена из Git.

Сборщик получает список буклетов из запроса, реально используемого страницей сайта:
https://dixy.ru/ajax/json.php?block=booklets

Проверяет даты и ссылки, скачивает PDF через браузер, проверяет сигнатуру и сохраняет
SHA-256. При наличии pdftotext дополнительно сохраняет текст с расположением блоков.
latest.json заменяется только после успешной загрузки; предыдущий выпуск остаётся в своей папке.
status.json содержит результат последней попытки. Дата окончания буклета считается по Москве,
включительно до конца последнего дня.

PDF содержит несколько цен у одного товара: цена без карты, по карте, при покупке
нескольких единиц, средняя цена по сети. Текстовая выгрузка ещё не является таблицей
цен, пригодной для автоматического расчёта бюджета. Цены PDF пока не импортируются
в catalogue_price_references и не подменяют обычную цену товара.

Для дальнейшего структурированного импорта понадобятся поля regularPrice,
promotionPrice, requiresLoyaltyCard, minimumQuantity, validFrom, validTo, region,
packageWeightG и проверенное сопоставление продукта. Сначала проверять условия акции,
затем выбирать применимую цену.

Добавлены сборщики Магнита, Глобуса, Перекрёстка и Пятёрочки, общий последовательный
запуск и импорт обычных региональных справочных цен. Инструкции и текущие ограничения:
[RETAIL_COLLECTORS.md](RETAIL_COLLECTORS.md). Пятёрочка может прерывать автоматическую
загрузку проверкой браузера; это не считается успешной выгрузкой каталога.
