# SmartMeal · дизайн интерфейса

16 октября 2026. Реализованные макеты трёх основных потоков и карточки рецепта, desktop 1440 px / mobile 390 px. Визуальное направление: тёплый нейтральный фон, зелёный основной акцент, спокойные карточки и мягкие статусы. Типографика системная, все экраны используют общие токены из frontend/src/styles.css.

## Меню дня

[Desktop](today-desktop.png) · [Mobile](today-mobile.png)

Суточная цель и сумма плана, БЖУ, бюджет периода, блюда по приёмам пищи, порции, закрепление и ручной выбор. Сумма называется запланированной, не фактически съеденной. Автоподбор не выдаёт фиктивный результат.

## Покупки

[Desktop](shopping-desktop.png) · [Mobile](shopping-mobile.png)

Крупные отметки, количества упаковок и потребность, раскрываемый источник/остаток, статусы качества цены, стоимость еды отдельно от покупки. При неполных данных — известная часть без ложного подтверждения бюджета. Обновление списка после изменений требует подтверждения.

## Состояния

Loading/skeleton; пустая выдача; ошибка API с повтором; недоступный backend-модуль; ProblemDetail с полями; устаревший список; неизвестная/устаревшая цена; риск и превышение бюджета; offline с блокировкой отметок. Макеты сделаны на учебных данных и не подтверждают готовность серверных функций.

## Проверка

11 маршрутов × 4 ширины (360, 390, 768, 1440), горизонтального переполнения не обнаружено. Клавиатурный focus, нативные modal dialog и подписи полей предусмотрены. Полный аудит WCAG, увеличение текста на всех сочетаниях устройств и физические Android/iOS остаются отдельной приёмкой. Фотографии в демо — удалённые иллюстрации Unsplash, не изображения товаров реальных магазинов.
